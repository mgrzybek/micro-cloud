# Releasing

This project follows common CNCF release hygiene:

- **[Conventional Commits](https://www.conventionalcommits.org/)** — enforced by `commitlint`
  (pre-commit `commit-msg` hook). They drive the changelog.
- **[Semantic Versioning](https://semver.org/)** — tags are `vMAJOR.MINOR.PATCH`.
- **[Keep a Changelog](https://keepachangelog.com/)** — `CHANGELOG.md`, generated by
  [git-cliff](https://git-cliff.org) (`cliff.toml`).
- **Signed tags** — release tags are GPG-signed (`git tag -s`).
- **Artifacts** — pushing a `v*.*.*` tag triggers `.github/workflows/release.yml`, which publishes the
  `ring0` Flux manifests as an OCI artifact (`oci://ghcr.io/mgrzybek/micro-cloud:<tag>` + `latest`) and
  creates the matching **GitHub Release** with notes derived from the commits.

## Versioning (pre-1.0)

While on `0.y.z`:

- new features → bump the **minor** (`0.1.0`, `0.2.0`, …);
- bug fixes / docs / internal changes → bump the **patch** (`0.1.1`, …);
- anything breaking is called out in the changelog (no major bump before `1.0.0`).

## Cutting a release

Prerequisite: `brew install git-cliff` (or see git-cliff.org for other platforms).

1. Make sure `main` is up to date and green, then pick the next version `vX.Y.Z`.

2. Prepend the new section to the changelog from the unreleased commits:

   ```bash
   git cliff --unreleased --tag vX.Y.Z --prepend CHANGELOG.md
   ```

   Review `CHANGELOG.md` and lightly curate it (dedupe, drop noise, fix wording).

3. Commit the changelog:

   ```bash
   git add CHANGELOG.md
   git commit -m "chore(release): vX.Y.Z"
   ```

4. Create the signed tag and push everything:

   ```bash
   git tag -s vX.Y.Z -m "release: vX.Y.Z"
   git push --follow-tags
   ```

5. CI (`release.yml`) then pushes the OCI artifact (+ `latest`) and opens the GitHub Release. Verify:

   ```bash
   gh release view vX.Y.Z
   ```

> The GitHub Release notes are regenerated in CI with `git cliff --latest` from the tagged commit, so
> they always match the tag even if the committed `CHANGELOG.md` was edited afterwards.
